# papers

Code, simulation results, and reproducibility material for research papers, one folder per paper.

| Folder | Paper | Contents |
|---|---|---|
| `tilted-spikeslab/` | The determinant-tilted spike-and-slab prior for the Gaussian graphical model: construction, properties, and Bayesian inference (Marsman et al., in preparation) | `code/`: R and C++ sources, verification scripts, archived results, figures, tables. See `tilted-spikeslab/code/README.md`. |
| `inclusion-bf-tutorial/` | Inclusion Bayes factors for psychological networks: A tutorial on evaluating evidence of edge presence and absence (Marsman, in preparation) | `code/`: R scripts for the worked example, the robustness checks, and the figures and tables, plus the archived checkpoints of the known-truth simulation study. See `inclusion-bf-tutorial/code/README.md`. |

Manuscripts are not kept in this repository.
